Shopping Cart.

GOALS:
Display three products: Apple ($2), Banana ($3), and Orange ($4).

Each product has an Add button.

Adding the same product multiple times increases its quantity rather than creating duplicate entries in the basket.

Show each basket item's name, quantity, and subtotal.

Display the combined basket total.

Allow individual products to be removed from the basket.

Include a button to clear the entire basket.

Keep the basket's data in JavaScript rather than treating DOM elements as the source of truth.
